[ Mistura de cores com LED RGB ]

Criar cores misturando luz vermelha, verde e azul em um LED RGB, controlando cada cor com PWM.

  • ⏱ 40 a 50 min
  • 🧪 Tinkercad + montagem real
  • 🔌 Arduino Uno R3

Você vai aprender

  • Sistema aditivo de cores (RGB)
  • Três saídas PWM ao mesmo tempo
  • Criar e usar funções próprias e laços for

Componentes

  • 1× Arduino Uno R3 + cabo USB
  • 1× Protoboard
  • 1× LED RGB de cátodo comum
  • 3× Resistores de 220 Ω

Ligações

Pino 11 (~PWM)Resistor 220 Ω → perna R (vermelho)
Pino 10 (~PWM)Resistor 220 Ω → perna G (verde)
Pino 9 (~PWM)Resistor 220 Ω → perna B (azul)
GNDTrilha (−) → perna comum (a mais longa)
1

Teste no Tinkercad

Monte e simule o circuito no computador antes de mexer nos componentes.

  1. Crie um novo circuito com Arduino Uno R3 e uma protoboard pequena.
  2. Arraste um LED RGB e encaixe as 4 pernas em linhas diferentes. No inspetor, confira se a polaridade está como Cátodo comum.
  3. Passe o mouse sobre cada perna para ver o nome dela (vermelho, verde, azul e cátodo). Atenção: no Tinkercad a ordem das pernas pode ser diferente da do LED real; ligue pelo nome, não pela posição.
  4. Coloque um resistor de 220 Ω em cada perna de cor. Ligue: pino 11 → resistor do vermelho, pino 10 → resistor do verde, pino 9 → resistor do azul.
  5. Ligue a perna do cátodo ao GND.
  6. Em Código → Texto, cole o código desta página e clique em Iniciar simulação. O LED deve mostrar vermelho, verde, azul, amarelo, ciano, magenta e branco.
2

Montagem real

Agora com a placa, a protoboard e os componentes de verdade.

  1. Identifique as pernas do LED RGB: a mais longa é a comum. Na maioria dos modelos de cátodo comum a ordem é R · comum · G · B.
  2. Com o USB desconectado, encaixe o LED com cada perna em uma linha. Coloque um resistor de 220 Ω em série com cada perna de cor, passando por cima do canal central, como no esquema.
  3. Ligue os pinos 11, 10 e 9 às linhas dos resistores do vermelho, verde e azul. Ligue a perna comum ao GND (pela trilha −).
  4. Conecte o USB, selecione Arduino Uno e a porta, cole o código e clique em Carregar.
  5. Se as cores aparecerem trocadas (por exemplo, verde no lugar de azul), não precisa remontar: troque os números dos pinos no início do código.
  6. Se o LED ficar aceso quando deveria apagar e as cores parecerem “invertidas”, ele é de ânodo comum: ligue a perna longa no 5V e mude ANODO_COMUM para true.

⚠️ Sempre monte ou altere o circuito com o cabo USB desconectado. Nunca ligue o 5V diretamente no GND.

/*
  Oficina de Robótica SELFÍS — Prática 3: Mistura de cores com LED RGB
  Placa: Arduino Uno R3
  Ligações: perna R -> resistor 220 ohms -> pino 11
            perna G -> resistor 220 ohms -> pino 10
            perna B -> resistor 220 ohms -> pino 9
            perna comum (a mais longa) -> GND  (LED de CÁTODO comum)
*/

const int PINO_R = 11;
const int PINO_G = 10;
const int PINO_B = 9;

// Se o seu LED for de ÂNODO comum (perna longa no 5V), troque false por true
const bool ANODO_COMUM = false;

void setup() {
  pinMode(PINO_R, OUTPUT);
  pinMode(PINO_G, OUTPUT);
  pinMode(PINO_B, OUTPUT);
}

// Função que acende o LED com uma mistura de vermelho, verde e azul (0 a 255 cada)
void cor(int r, int g, int b) {
  if (ANODO_COMUM) {       // no ânodo comum a lógica é invertida
    r = 255 - r;
    g = 255 - g;
    b = 255 - b;
  }
  analogWrite(PINO_R, r);
  analogWrite(PINO_G, g);
  analogWrite(PINO_B, b);
}

void loop() {
  // Cores primárias da luz
  cor(255, 0, 0);     delay(1000);   // vermelho
  cor(0, 255, 0);     delay(1000);   // verde
  cor(0, 0, 255);     delay(1000);   // azul

  // Cores secundárias (soma de duas primárias)
  cor(255, 255, 0);   delay(1000);   // amarelo  = R + G
  cor(0, 255, 255);   delay(1000);   // ciano    = G + B
  cor(255, 0, 255);   delay(1000);   // magenta  = R + B

  // Todas juntas
  cor(255, 255, 255); delay(1000);   // branco   = R + G + B

  // Transição suave: do vermelho para o azul
  for (int i = 0; i <= 255; i++) {
    cor(255 - i, 0, i);
    delay(8);
  }
  cor(0, 0, 0);       delay(500);    // apagado
}

Como funciona?

Dentro do LED RGB há três pequenos LEDs. Cada um é controlado por um pino PWM, com valores de 0 (apagado) a 255 (brilho máximo).

A luz se mistura pelo sistema aditivo: vermelho + verde = amarelo; verde + azul = ciano; vermelho + azul = magenta; as três juntas = branco. Com 256 níveis por cor, são mais de 16 milhões de combinações possíveis.

A função cor(r, g, b) foi criada por nós para não repetir três analogWrite a cada cor. O laço for faz a transição suave, mudando o valor de 1 em 1.

Desafios

  1. Crie uma cor nova, como laranja: cor(255, 80, 0).
  2. Junte as Práticas 2 e 3: use o potenciômetro para escolher a cor do LED (solução abaixo).
  3. Faça um arco-íris contínuo, com transições suaves entre todas as cores.

/*
  Oficina de Robótica SELFÍS — Desafio da Prática 3
  Gire o potenciômetro para escolher a cor do LED RGB (roda de cores).
  Montagem: a da Prática 3 + o potenciômetro da Prática 2 (5V, A0, GND).
*/
const int PINO_R = 11;
const int PINO_G = 10;
const int PINO_B = 9;
const int PINO_POT = A0;

void setup() {
  pinMode(PINO_R, OUTPUT);
  pinMode(PINO_G, OUTPUT);
  pinMode(PINO_B, OUTPUT);
}

void cor(int r, int g, int b) {
  analogWrite(PINO_R, r);
  analogWrite(PINO_G, g);
  analogWrite(PINO_B, b);
}

void loop() {
  // Divide o giro em 3 trechos de 256 passos: vermelho -> verde -> azul -> vermelho
  int h = map(analogRead(PINO_POT), 0, 1023, 0, 767);

  if (h < 256) {              // vermelho -> verde (passa pelo amarelo)
    cor(255 - h, h, 0);
  } else if (h < 512) {       // verde -> azul (passa pelo ciano)
    h = h - 256;
    cor(0, 255 - h, h);
  } else {                    // azul -> vermelho (passa pelo magenta)
    h = h - 512;
    cor(h, 0, 255 - h);
  }
  delay(20);
}

Não funcionou?

Uma das cores não acende
Confira o resistor e o fio daquela cor; teste trocando o pino no código.
As cores estão trocadas
A ordem das pernas varia entre fabricantes. Troque os números de PINO_R, PINO_G e PINO_B.
Tudo aceso e as cores “ao contrário”
O LED é de ânodo comum: perna longa no 5V e ANODO_COMUM = true.
