[ Dimmer com potenciômetro ]

Controlar o brilho de um LED girando um potenciômetro: o Arduino lê um valor analógico e responde com um sinal PWM.

  • ⏱ 40 a 50 min
  • 🧪 Tinkercad + montagem real
  • 🔌 Arduino Uno R3
Ir para o código ↓Roteiro passo a passo

Você vai aprender

  • Entrada analógica: analogRead() e o conversor de 0 a 1023
  • Saída PWM: analogWrite() de 0 a 255
  • Conversão de escalas com map() e uso do Monitor Serial

Componentes

  • 1× Arduino Uno R3 + cabo USB
  • 1× Protoboard
  • 1× Potenciômetro de 10 kΩ
  • 1× LED 5 mm
  • 1× Resistor de 220 Ω
  • 5× Jumpers macho-macho

Ligações

A0Potenciômetro — pino 2 (meio, cursor)
GNDTrilha (−) → potenciômetro — pino 3 (ponta)
Pino 11 (~PWM)LED — perna longa (+)
LED — perna curta (−)Resistor de 220 Ω → trilha (−)
1

Teste no Tinkercad

Monte e simule o circuito no computador antes de mexer nos componentes.

  1. Crie um novo circuito e coloque o Arduino Uno R3 e uma protoboard pequena.
  2. Arraste um potenciômetro para a protoboard, com cada uma das 3 pernas em uma linha diferente. No inspetor, ajuste a resistência para 10 kΩ.
  3. Ligue: 5V → perna de uma ponta do potenciômetro; A0 → perna do meio; a outra ponta → GND (pela trilha −).
  4. Coloque o LED e um resistor de 220 Ω (perna curta → resistor → trilha −). Ligue o pino 11 à perna longa do LED.
  5. Em Código → Texto, cole o código desta página e clique em Iniciar simulação.
  6. Durante a simulação, clique no potenciômetro e gire o botão com o mouse: o brilho do LED muda. Abra o Monitor serial (parte de baixo do painel de código) para ver os valores lidos.
2

Montagem real

Agora com a placa, a protoboard e os componentes de verdade.

  1. Com o USB desconectado, encaixe o potenciômetro na protoboard, com as 3 pernas em linhas diferentes.
  2. Ligue 5V do Arduino a uma ponta, A0 ao pino do meio e a outra ponta ao GND (use a trilha −).
  3. Monte o LED com o resistor de 220 Ω até a trilha (−) e ligue o pino 11 à perna longa.
  4. Conecte o USB, selecione Arduino Uno e a porta, cole o código e clique em Carregar.
  5. Abra Ferramentas → Monitor Serial e ajuste a velocidade para 9600. Gire o potenciômetro e acompanhe a leitura, a tensão e o brilho.
  6. Extra: abra Ferramentas → Plotter Serial para ver um gráfico dos valores em tempo real.

⚠️ Sempre monte ou altere o circuito com o cabo USB desconectado. Nunca ligue o 5V diretamente no GND.

#< código >

pratica2_potenciometro.ino Baixar .ino
/*
  Oficina de Robótica SELFÍS — Prática 2: Dimmer com potenciômetro
  Placa: Arduino Uno R3
  Ligações: potenciômetro -> 5V, A0 (pino do meio) e GND
            LED -> pino 11 (PWM) com resistor de 220 ohms até o GND
*/

const int PINO_POT = A0;   // entrada analógica: lê de 0 a 1023
const int PINO_LED = 11;   // saída PWM (~): escreve de 0 a 255

void setup() {
  pinMode(PINO_LED, OUTPUT);
  Serial.begin(9600);      // abre a comunicação com o computador (Monitor Serial)
}

void loop() {
  // 1) Lê a posição do potenciômetro (0 V -> 0 ... 5 V -> 1023)
  int leitura = analogRead(PINO_POT);

  // 2) Converte a escala 0–1023 para 0–255 (a escala do PWM)
  int brilho = map(leitura, 0, 1023, 0, 255);

  // 3) Aplica o brilho no LED
  analogWrite(PINO_LED, brilho);

  // 4) Mostra os valores no Monitor Serial
  float tensao = leitura * (5.0 / 1023.0);
  Serial.print("Leitura: ");
  Serial.print(leitura);
  Serial.print("  |  Tensao: ");
  Serial.print(tensao, 2);
  Serial.print(" V  |  Brilho: ");
  Serial.println(brilho);

  delay(100);              // pequena pausa para o Monitor Serial não "correr"
}

Como funciona?

O potenciômetro ligado entre 5 V e GND é um divisor de tensão: o pino do meio entrega uma tensão entre 0 V e 5 V conforme a posição do eixo.

O conversor analógico-digital do Arduino (10 bits) transforma essa tensão em um número de 0 a 1023. Cada passo vale cerca de 5 V ÷ 1023 ≈ 4,9 mV.

O LED não recebe uma tensão “intermediária”: o pino 11 liga e desliga centenas de vezes por segundo (PWM). O valor de 0 a 255 define quanto tempo ele fica ligado em cada ciclo; nossos olhos percebem isso como brilho maior ou menor. Por isso o LED precisa estar em um pino com ~ (3, 5, 6, 9, 10 ou 11).

Desafios

  1. Inverta o controle: girar para a direita deve apagar o LED. (Dica: troque a ordem dos números no map.)
  2. Use o potenciômetro para controlar a velocidade com que o LED pisca (solução abaixo).
  3. Acenda o LED só quando a leitura passar de 512, usando if.
Ver a solução do desafio 2
desafio2_pisca_variavel.ino Baixar .ino
/*
  Oficina de Robótica SELFÍS — Desafio da Prática 2
  O potenciômetro controla a VELOCIDADE com que o LED pisca.
  Mesma montagem da Prática 2.
*/
const int PINO_POT = A0;
const int PINO_LED = 11;

void setup() {
  pinMode(PINO_LED, OUTPUT);
}

void loop() {
  int leitura = analogRead(PINO_POT);            // 0 a 1023
  int tempo = map(leitura, 0, 1023, 50, 1000);   // 50 ms (rápido) a 1000 ms (lento)

  digitalWrite(PINO_LED, HIGH);
  delay(tempo);
  digitalWrite(PINO_LED, LOW);
  delay(tempo);
}

Não funcionou?

O LED só acende ou apaga, sem meio-termo
Ele não está em um pino PWM. Use o pino 11 (ou outro com ~).
A leitura fica “pulando” ou parada em 0/1023
O pino do meio do potenciômetro não está no A0, ou falta a ligação do 5V/GND.
O Monitor Serial mostra caracteres estranhos
Ajuste a velocidade do Monitor para 9600, igual ao Serial.begin(9600).
