Prática 1

[ Semáforo ]

Programar três LEDs para funcionarem como um semáforo, usando saídas digitais do Arduino.

  • ⏱ 30 a 40 min
  • 🧪 Tinkercad + montagem real
  • 🔌 Arduino Uno R3
Ir para o código ↓Roteiro passo a passo

Você vai aprender

  • Saídas digitais: pinMode, digitalWrite, HIGH e LOW
  • Uso de delay() para controlar o tempo
  • Polaridade do LED e função do resistor

Esquema ilustrado

Toque na imagem para ampliar

Componentes

  • 1× Arduino Uno R3 + cabo USB
  • 1× Protoboard
  • 3× LEDs 5 mm (vermelho, amarelo e verde)
  • 3× Resistores de 220 Ω (vermelho · vermelho · marrom)
  • 4× Jumpers macho-macho

Ligações

Pino 10LED vermelho — perna longa (+)
Pino 9LED amarelo — perna longa (+)
Pino 8LED verde — perna longa (+)
Perna curta (−) de cada LEDResistor de 220 Ω → trilha negativa (−)
GNDTrilha negativa (−) da protoboard
1

Teste no Tinkercad

Monte e simule o circuito no computador antes de mexer nos componentes.

  1. Acesse tinkercad.com, entre na sua conta (ou na conta da turma) e clique em Circuitos → Criar novo circuito.
  2. No painel de componentes (à direita), procure Arduino Uno R3 e arraste-o para a área de trabalho. Faça o mesmo com uma placa de ensaio (protoboard) pequena.
  3. Arraste 3 LEDs para a protoboard. Clique em cada um e escolha a cor no inspetor: vermelho, amarelo e verde. Encaixe cada LED com as pernas em linhas numeradas diferentes.
  4. Arraste 3 resistores. O Tinkercad cria o resistor com 1 kΩ: clique nele e mude a Resistência para 220 Ω. Ligue cada resistor entre a perna curta (cátodo) de um LED e a trilha negativa (−).
  5. Crie os fios clicando em um furo e depois no outro: pino 10 → perna longa do vermelho, pino 9 → amarelo, pino 8 → verde, e GND → trilha (−). Dica: clique no fio para mudar a cor (preto para GND).
  6. Clique em Código, troque Blocos por Texto (confirme o aviso), apague o exemplo e cole o código desta página.
  7. Clique em Iniciar simulação. Os LEDs devem acender na ordem verde → amarelo → vermelho. Se algum LED não acender, passe o mouse sobre as pernas: o Tinkercad mostra qual é o ânodo e qual é o cátodo.
2

Montagem real

Agora com a placa, a protoboard e os componentes de verdade.

  1. Com o cabo USB desconectado, encaixe os três LEDs na protoboard, como no esquema. A perna mais longa (ânodo, +) fica na linha que vai receber o fio do pino.
  2. Encaixe um resistor de 220 Ω entre a linha da perna curta de cada LED e a trilha negativa (−).
  3. Ligue os jumpers: pino 10, 9 e 8 do Arduino nas linhas das pernas longas dos LEDs vermelho, amarelo e verde. Ligue um GND do Arduino na trilha (−).
  4. Confira cada ligação com o esquema e com a tabela de ligações antes de seguir.
  5. Conecte o cabo USB ao computador e abra a Arduino IDE. Em Ferramentas → Placa, escolha Arduino Uno; em Ferramentas → Porta, escolha a porta que apareceu (COM3, COM4… no Windows).
  6. Cole o código, clique em ✓ Verificar e depois em → Carregar. Quando aparecer “Carregamento concluído”, observe o semáforo funcionando.

⚠️ Sempre monte ou altere o circuito com o cabo USB desconectado. Nunca ligue o 5V diretamente no GND.

#< código >

pratica1_semaforo.ino Baixar .ino
/*
  Oficina de Robótica SELFÍS — Prática 1: Semáforo
  Placa: Arduino Uno R3
  Ligações: LED vermelho -> pino 10 | LED amarelo -> pino 9 | LED verde -> pino 8
            (cada LED com um resistor de 220 ohms ligado ao GND)
*/

// 1) Damos nomes aos pinos: fica mais fácil ler e alterar o código
const int LED_VERMELHO = 10;
const int LED_AMARELO  = 9;
const int LED_VERDE    = 8;

// 2) Tempos de cada fase, em milissegundos (1000 ms = 1 segundo)
const int TEMPO_VERDE    = 4000;
const int TEMPO_AMARELO  = 1500;
const int TEMPO_VERMELHO = 4000;

void setup() {
  // setup() roda UMA vez, quando a placa liga
  pinMode(LED_VERMELHO, OUTPUT);  // o pino vai ENVIAR sinal (saída)
  pinMode(LED_AMARELO,  OUTPUT);
  pinMode(LED_VERDE,    OUTPUT);
}

void loop() {
  // loop() repete para sempre

  // Fase VERDE
  digitalWrite(LED_VERDE, HIGH);   // HIGH = 5 V = LED aceso
  digitalWrite(LED_AMARELO, LOW);  // LOW  = 0 V = LED apagado
  digitalWrite(LED_VERMELHO, LOW);
  delay(TEMPO_VERDE);              // espera

  // Fase AMARELA
  digitalWrite(LED_VERDE, LOW);
  digitalWrite(LED_AMARELO, HIGH);
  delay(TEMPO_AMARELO);

  // Fase VERMELHA
  digitalWrite(LED_AMARELO, LOW);
  digitalWrite(LED_VERMELHO, HIGH);
  delay(TEMPO_VERMELHO);
}

Como funciona?

Cada pino digital do Arduino só tem dois estados: HIGH (5 V) ou LOW (0 V). Com digitalWrite(pino, HIGH) o pino fornece 5 V e a corrente passa pelo LED e pelo resistor até o GND, acendendo o LED.

O resistor de 220 Ω limita a corrente a cerca de 14 mA. Sem ele, a corrente subiria muito e poderia queimar o LED e danificar o pino do Arduino.

A função loop() se repete sem parar; por isso o semáforo continua trocando de cor indefinidamente. O delay() “congela” o programa pelo tempo indicado, em milissegundos.

Desafios

  1. Mude os tempos para deixar o verde aceso por 6 s e o vermelho por 3 s.
  2. Faça o semáforo entrar em modo alerta: o amarelo pisca 5 vezes ao fim de cada ciclo (solução abaixo).
  3. Monte um segundo semáforo, de pedestres, com 2 LEDs (vermelho e verde), sincronizado com o primeiro.
Ver a solução do desafio 2
desafio1_pisca_alerta.ino Baixar .ino
/*
  Oficina de Robótica SELFÍS — Desafio da Prática 1
  Semáforo com "modo alerta": depois de cada ciclo, o amarelo pisca 5 vezes.
  Mesma montagem da Prática 1.
*/
const int LED_VERMELHO = 10;
const int LED_AMARELO  = 9;
const int LED_VERDE    = 8;

void setup() {
  pinMode(LED_VERMELHO, OUTPUT);
  pinMode(LED_AMARELO,  OUTPUT);
  pinMode(LED_VERDE,    OUTPUT);
}

void apagaTudo() {
  digitalWrite(LED_VERMELHO, LOW);
  digitalWrite(LED_AMARELO,  LOW);
  digitalWrite(LED_VERDE,    LOW);
}

void loop() {
  apagaTudo(); digitalWrite(LED_VERDE, HIGH);    delay(4000);
  apagaTudo(); digitalWrite(LED_AMARELO, HIGH);  delay(1500);
  apagaTudo(); digitalWrite(LED_VERMELHO, HIGH); delay(4000);

  // Modo alerta: o laço "for" repete o bloco 5 vezes
  apagaTudo();
  for (int i = 0; i < 5; i++) {
    digitalWrite(LED_AMARELO, HIGH);
    delay(400);
    digitalWrite(LED_AMARELO, LOW);
    delay(400);
  }
}

Não funcionou?

Nenhum LED acende
Confira o GND ligado na trilha (−) e se os resistores vão até essa mesma trilha.
Um LED não acende
Ele provavelmente está invertido: gire 180°. Confira também se o fio está na mesma linha da perna longa.
Erro ao carregar o código
Verifique a placa (Arduino Uno) e a porta em Ferramentas. Em placas genéricas, pode ser preciso instalar o driver CH340.
